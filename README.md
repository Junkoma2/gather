# gather

思考の近さを、動く円として眺める小さなWebアプリです。

## なぜ作ったか

考えを整理するとき、リストや箇条書きに並べると「順番」が生まれてしまいます。でも実際の思考は順番より「近さ」で繋がっていることが多い。
gatherは考えを円として置くと、色の近い円が引き合い、遠い色の円が離れていくアプリです。整理するより、眺めることで気づくことを目的にしています。

## 主な機能

- 考えを名前だけですぐに追加でき、色・サイズは任意で調整できる
- canvas上で円が物理演算により自然に動く（色が近いほど引き合う）
- 円をドラッグして位置を変えられる
- 「つなぐ」モードで2つの円を選ぶと色を近づけられる
- 円を重ねるとブレンドを提案するポップアップが表示される
- データのエクスポート・インポート（JSON）
- pull-to-refresh でアプリを更新

## 使い方

1. 「+」ボタンから考えを追加する（名前だけで置け、色・サイズは開けば調整できる）
2. 追加した円がcanvas上で自動的に配置される
3. 円をドラッグして動かしたり、タップして編集・削除できる
4. 「つなぐ」ボタンで2つの円を選ぶと、色が少し近づく

## 技術スタック

- HTML / CSS / JavaScript（ビルドステップなし）
- Canvas 2D API（物理演算ループ・描画）
- Service Worker（オフライン対応）
